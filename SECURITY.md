# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of VectorCut Studio seriously. If you believe you have found a security vulnerability, please do **not** report it publicly through a GitHub issue.

Instead, please send an email or submit a private security advisory through GitHub:

1. Go to the **Security** tab of the repository.
2. Click **Report a vulnerability**.
3. Provide a detailed summary, proof of concept, and steps to reproduce.

We will acknowledge receipt within 48 hours and work with you on a resolution before any public disclosure.
